An official implementation for IJCAI-26 paper "AnoMamba: Aligning Reconstruction with Time Series Anomaly Detection via Selective Global Dependency Modeling"



### Dataset process

```
cat data_process/multivariate.zip.part_* > data_process/multivariate.zip
unzip data_process/univariate.zip -d data_process/
unzip data_process/multivariate.zip -d data_process/
```



### Run the code

```
bash run.sh
```
